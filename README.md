# Timescale API

WebAPI-приложение для обработки и анализа timescale-данных из CSV-файлов.

## Возможности

API предоставляет три основных метода:

- загрузка и обработка CSV-файла;
- получение результатов обработки с поддержкой фильтрации;
- получение последних 10 значений для указанного файла.

При загрузке файла выполняется валидация данных, сохранение значений в PostgreSQL и расчёт интегральных показателей: дельты времени, среднего и медианного значений, минимального и максимального значений и среднего времени выполнения.

Если файл с таким именем уже существует, его данные заменяются новыми.

## Технологии

- **.NET 9**
- **ASP.NET Core Web API**
- **Entity Framework Core**
- **PostgreSQL**
- **Swagger / OpenAPI**
- **Docker / Docker Compose**
- **xUnit**
